# Auth Screen — Responsive Behavior Matrix

> **Breakpoints:** Mobile (320px - 639px), Tablet (640px - 1023px), Desktop (1024px+)  

---

## 1. Responsive Transition Rules

- **Mobile (< 640px)**: Single column stack, 100% width fluid card with `16px` margins. Top brand logo centered above form card.
- **Tablet (640px - 1023px)**: Form card constrained to `480px` max-width, vertically and horizontally centered in screen.
- **Desktop (1024px+)**: Two-column split layout (Left: Brand Showcase, Right: Auth Form).
- **Keyboard Handling (Mobile)**: Input field scroll-into-view behavior with safe viewport padding.
