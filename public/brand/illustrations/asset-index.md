# OPOS Master Asset Index

## Modular Component Registry
The illustration system is constructed from reusable vector primitives:
1. **PAW_SYMBOL:** Standardized pet paw icon.
2. **GLASS_CARD_PLATE:** Glassmorphic white surface with hairline border.
3. **MEDICAL_SHIELD:** Parasite and health protection shield badge.
4. **VACCINE_VIAL:** Smart digital vaccine container.
5. **NUTRITION_BOWL:** Calorie and food portion tracking bowl.
6. **HEART_PULSE_CARD:** Vital metric line graph container.

All components are stored as vector definitions and can be combined to build future module illustrations.
