# OPOS Future Expansion Guide

## Guidelines for Adding New Module Illustrations
1. **Directory Structure:** Create a new folder under `public/brand/illustrations/[new-module]/` containing `svg/`, `png/`, `preview/`, and `README.md`.
2. **Color Mapping:** Pick an existing domain color triplet or register a new one in OPOS Color System before creation.
3. **Defs & Filters:** Always reuse `#soft-shadow`, `#primary-grad`, and `#glass-card-grad`.
4. **Manifest Registration:** Add the new item to `illustration-manifest.json` with versioning and screen mapping.
